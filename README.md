# AI Productivity Pal

Create an AI-powered productivity assistant with the following features:

1. Smart Email Generator:

   - Compose professional emails based on short user inputs (e.g., "thank client for meeting").

   - Suggest subject lines and structure with greetings, context, and closing.

   - Allow customization for tone (formal, friendly, persuasive).

2. Meeting Notes Summarizer:

   - Automatically summarize meeting transcripts or uploaded notes.

   - Highlight key decisions, action items, and deadlines.

   - Provide concise bullet-point summaries for quick review.

3. AI Task Planner/Scheduler:

   - Convert action items into tasks with deadlines and priorities.

   - Suggest optimal scheduling based on calendar availability.

   - Allow task categorization (work, personal, urgent).

   - Provide reminders and progress tracking.

Design:

- Clean, modern dashboard interface.

- Integration with email, calendar, and task management tools.

- Mobile-friendly layout with intuitive navigation.
